Body copy is where contrast failures actually hurt. This paragraph is set at 16 px, which counts as normal text under WCAG 2.2 — it needs a contrast ratio of at least 4.5:1 to pass Level AA, and 7:1 for AAA.
Small print, captions and placeholder text still need the same 4.5:1 — there is no exemption for de-emphasised text, only for text that is genuinely disabled.
